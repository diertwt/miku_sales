ИНТЕГРАЦИЯ MIKU_SALES С EXCEL

Что изменено:
- core/excel_export.py — экспорт продаж в лист «Продажи».
- ui/main_window.py — меню Excel для выбора книги и ручной синхронизации.
- ui/tab_sales.py — автоматическая синхронизация при обновлении списка продаж.
- requirements.txt — добавлена зависимость openpyxl.

УСТАНОВКА В ИСХОДНЫЙ ПРОЕКТ
1. Сделайте резервную копию проекта и папки data (особенно data/sales.db и data/receipts).
2. Распакуйте архив поверх исходного проекта, сохранив структуру папок.
3. В активном виртуальном окружении выполните:
   pip install -r requirements.txt
4. Запустите приложение из исходников и откройте меню «Excel» -> «Выбрать файл Excel…».
5. Выберите или создайте файл .xlsx. При первом экспорте будет создан лист «Продажи».
6. Пересоберите EXE своей обычной командой PyInstaller с build.spec.

КАК РАБОТАЕТ
- Путь к книге сохраняется в настройках Windows через QSettings.
- При сохранении новой/изменённой продажи лист «Продажи» полностью пересобирается из базы.
- Остальные листы выбранной книги не меняются.
- Ручные рекламные расходы на других листах остаются нетронутыми.
- Есть команда «Excel» -> «Синхронизировать сейчас».

ВАЖНО
- Выбирайте именно .xlsx, не .xls и не .xlsm.
- Лист «Продажи» считается служебным листом синхронизации: его содержимое заменяется данными базы при каждом экспорте.
- Не храните рекламные расходы на листе «Продажи» — используйте отдельный лист.
- Если Excel блокирует файл, закройте книгу и выберите «Синхронизировать сейчас».
- Архив патча не содержит вашу базу данных и чеки; они остаются в исходном проекте.
